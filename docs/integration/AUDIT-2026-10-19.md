## Divergences conservées et explicitement isolées

Le `containers` récent de Dan choisit les nœuds en round-robin, divise également les tailles et rapporte l'espace physique libre. Le remplacer silencieusement dans le serveur-zone actif casserait le contrat HRW/source locale/quota net/extents existants. Le module complet est donc conservé séparément, avec une note ; aucun faux adaptateur prétendant préserver ces sémantiques n'est ajouté. Son registre MQTT5 ne peut pas remplacer automatiquement l'autorité de snapshots déjà provisionnée : une migration des topics/identités doit être décidée et testée séparément.

Les anciennes passerelles vidéo Python importent `sendBlocks` puis `placement.py`, absent du dépôt, et proposent un placement round-robin. Elles restent disponibles mais hors du démarrage intégré. L'adaptateur nouveau réutilise la segmentation ; il suit exclusivement les plans du Go. Les blocs SIS de taille 125000 restent une couche crypto distincte, jamais assimilée aux extents de placement et jamais déclarée validée par SHA-256.

Le Central demeure hors du chemin média. Une passerelle web distincte reconstruit et sert le MP4 pour rendre le lecteur natif actuel testable. C'est un compromis documenté par rapport à la cible de lecture directe/HLS adaptative, pas une fonctionnalité de streaming finalisée.

Les sources du module legacy importé sont formatées avec gofmt. La normalisation locale des fins de ligne des autres fichiers Go ne change pas les blobs Git ni leur comportement.
